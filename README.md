**This adapter performs mathematical calculations for ioBroker.**

## Features

- Perform simple arithmetic operations (addition, subtraction, multiplication, division)
- Calculate averages of arrays of numbers
- Calculate energy consumption (watt-hours)
- Web-based configuration through ioBroker Admin interface
